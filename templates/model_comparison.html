Model Comparison

Comparison of machine learning models used for insurance claim cost prediction.

Linear Regression

Baseline regression model used to predict claim cost.

Ridge Regression

Regularized regression model using L2 regularization.

Random Forest

Ensemble machine learning model using multiple decision trees.

Model Performance

The models were evaluated using the same training and testing split.

Model MAE MSE RMSE R² Score
Linear Regression 0.4405 0.3149 0.5611 0.5180
Ridge Regression 0.4403 0.3145 0.5608 0.5185
Random Forest 0.4393 0.3186 0.5645 0.5122
Note: These metrics were calculated on the log-transformed claim loss used during model training.

MAE = Mean Absolute Error
MSE = Mean Squared Error
RMSE = Root Mean Squared Error
R² = Coefficient of Determination
